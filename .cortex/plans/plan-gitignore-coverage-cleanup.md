# Fix Gitignore Gaps and Remove Tracked Build Artifacts

**Status**: PENDING
**Priority**: HIGH
**Created**: 2026-02-28
**Type**: Fix
**Effort**: Small (10 min)

## Goal

Remove `coverage_consolidated.json` (2.5 MB build artifact) from git tracking and add missing coverage file patterns to `.gitignore`.

## Context

1. `coverage_consolidated.json` (2.5 MB) is tracked in git — it's a build artifact that inflates the repository.
2. `coverage.json` exists on disk but is not in `.gitignore` (only `coverage.xml` is listed).
3. Both are generated by test/coverage tools and should never be committed.

## Approach

Add missing patterns to `.gitignore`, then remove the tracked artifact from git index.

## Implementation Steps

1. **Add to `.gitignore`** after the existing `coverage.xml` line:

   ```gitignore
   coverage.json
   coverage_consolidated.json
   ```

2. **Remove from git tracking**: `git rm --cached coverage_consolidated.json`
3. **Verify**: `git ls-files -- coverage*.json` returns empty
4. **Commit** the `.gitignore` update and removal

## Dependencies

None.

## Success Criteria

- `coverage_consolidated.json` is no longer tracked by git
- Both `coverage.json` and `coverage_consolidated.json` are in `.gitignore`
- Repository size reduced by ~2.5 MB

## Testing Strategy

- **Coverage Target**: N/A (config-only change)
- **Verification**: `git ls-files -- coverage*.json` returns empty after commit
- **Regression**: No code changes — no test impact

## Risks & Mitigation

- **Risk**: None — removing a build artifact from tracking has no functional impact

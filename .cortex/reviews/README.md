# Reviews

Session optimization reports, investigations, and code reviews are stored here.

## Filename convention

**Suffix MUST always be `YYYY-MM-DDTHH-mm`.**

- Date: `YYYY-MM-DD` (e.g. `2026-01-28`)
- Time: `HH-mm` (hours and minutes, hyphen-separated, e.g. `17-58`)
- No date-only or other formats (e.g. no `-2026-01-28.md` without time, no `T-session`, no `T02` without minutes)

Examples:

- `session-optimization-2026-01-28T17-58.md`
- `session-hang-investigation-2026-01-30T15-00.md`
- `code-review-report-2026-01-15T00-00.md`

See `.cortex/synapse/agents/session-optimization-analyzer.md` and `.cortex/synapse/prompts/review.md` for creation rules.

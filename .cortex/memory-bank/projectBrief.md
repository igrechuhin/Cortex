## Design Principle: Compound Engineering

Cortex aims to make each unit of engineering work easier than the last; communication and output should become more efficient over time. Completed work lives in activeContext, future work in roadmap; learnings are captured via session optimization and memory bank updates. The workflow follows Plan → Work → Review → Compound; details and checklist are in the implement, commit, and analyze prompts (Synapse) and are loaded when you run those flows or use load_context.
